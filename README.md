![A screenshot of Studymate, showing the app's dashboard with recommended study plans and a greeting from the virtual assistant](/public/projects/studymate/1.webp)

### [**Pixi Paint**](https://github.com/k3vndev/pixi-paint)

Pixi Paint is a web-based pixel art platform built around a simple idea: making creative tools accessible instantly. It allows users to create, save, and share 8×8 pixel artwork directly in the browser, and without being an expert in design or pixel art.

The platform focuses on removing friction from the creative process, enabling users to start drawing, export their work, or publish it to a public gallery in seconds.

![A screenshot of Pixi Paint, showing a pixelated canvas with a duck painting](/public/projects/pixi-paint/1.webp)
